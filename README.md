# LeiMa

Suite of microservices to administer, monitor, manage permissions, and orchestrate long-running concurrent background tasks across external API providers.

See [CLAUDE.md](CLAUDE.md) for structure, stack and conventions.

- `services/` microservices
- `libs/` shared libraries (`libs/dotnet/LeiMa.Common` NuGet packages)
- `web/` React frontends
- `docs/` architecture, ADRs, user stories
- `tools/` scripts
